VERSIONED DATASETS

JSON · 최대 256 KiB
아래 샘플을 수정하고 새 버전으로 저장하세요. 기존 실행의 스냅샷은 바뀌지 않습니다. 실제 개인정보와 비밀은 입력하지 마세요.

    
버전 결과 비교
같은 데이터셋과 정책의 완료 결과를 비교합니다. 현재 조회한 실행을 후보로 사용합니다.
후보 실행을 조회한 뒤 기준 실행을 선택하세요.

    
로그인 세션 관리
현재 계정의 활성 세션을 확인합니다. 세션 종료는 해당 브라우저의 인증을 해제하며 접근 키를 철회하지 않습니다.

    
프로젝트 CI 접근 키
관리자만 발급·철회할 수 있습니다. 키는 선택한 프로젝트의 릴리스 게이트 검증에만 사용하며, 발급 시 한 번 표시됩니다.
이 창을 닫으면 키를 다시 조회할 수 없습니다. CI의 비밀 저장소에 보관하세요.

    
CI 릴리스 검증 기록
통과와 차단 판정을 함께 보존합니다. 기록 JSON은 과거 검증의 근거이며 배포 권한을 재사용하는 토큰이 아닙니다.

조직 감사 기록
현재 조직 전체의 불변 감사 이력입니다.
