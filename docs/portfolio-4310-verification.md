## 시연의 안전 범위

로그인은 촬영 전에 완료하고 비밀번호·접근 키·비공개 식별자·원시 응답을 노출하지 않는다. 기존 조회자로 기존 기록만 읽으며 평가 생성·검토 저장·최종 게이트 요청·배포는 수행하지 않는다. 화면에서 핵심 흐름을 직접 확인하지 못하면 설명과 확인 결과를 구분한다.

## 공개 자료 경계

최종 제출 후보 문서는 제품 개요와 이 확인 결과표 두 개로 제한한다. 기존 저장소 전체, 비공개 실행 원장, 환경 설정, 키, 브라우저 프로필, DB·볼륨, 원시 응답, 새 스택 화면과 합성 자막은 포함하지 않는다. 실제 4310 영상·자막은 별도 내용·노출 검토를 통과한 뒤에만 목록에 추가한다. 현재 영상 조건은 미완료·보류다. 추후 명시적 재개 전에는 촬영이나 자동 검토를 다시 시작하지 않는다.
