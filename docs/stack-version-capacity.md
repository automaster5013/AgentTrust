# 프로젝트별 버전 등록 용량 조회

4310 운영 관측의 버전 용량 표시를 4320의 실제 프로젝트별 등록 계약에 맞춰 연결한다. 기존 4310의 조직 전체 한도와 구분하며 현재 프로젝트의 에이전트·데이터셋을 각각 조회한다. 기존 한도 200개는 변경하지 않고 등록과 조회가 같은 상수를 사용한다.

인증된 `GET /api/version-capacity`는 RLS 범위의 단일 SELECT로 두 종류 보관 수를 집계한다. SQL에도 조직·프로젝트 조건을 각각 적용하며 폐기된 버전도 포함한다. 사용 수·한도·남은 수·한도 도달 여부·관측 시각을 반환한다. 기존 자료가 한도를 초과해도 사용 수를 숨기지 않고 남은 수를 0으로 표시한다. 한쪽 집계 실패를 0이나 부분 성공으로 처리하지 않는다.

조회자도 읽을 수 있으며 Gateway/BFF는 정확한 GET 경로만 허용한다. 버전·캠페인 화면은 초기/실패를 미확인으로 표시하고 명시적으로 조회한다. 새 조회·오류·취소·사용자 범위 변경 시 이전 관측을 제거하며 늦은 응답을 버린다. 관측은 예약이 아니며 실제 등록 시 기존 서버 한도 검사를 다시 수행한다. 원본 정리·버전 삭제·한도 변경을 수행하지 않는다.

API와 화면 모두 `reservationGranted=false`, `deploymentAuthority=false` 계약을 유지한다. DB 스키마·운영 데이터·계정·인증 설정 변경이나 실제 배포는 없다. 합성 후보의 API와 PostgreSQL 수치 대조, 원래 버전 행 지문 불변, 조회자·익명 거부, 실패·범위 치환과 모바일을 검증한 뒤 수용 결과를 별도 기록한다.
