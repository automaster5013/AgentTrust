# 평가 탐색과 다음 행동 안내

최근 평가에서 실행 ID·공급자·시나리오를 최대 64자로 검색한다. 검색은 앞뒤 공백과 영문 대소문자를 무시하며 판정·처리 상태 조건과 교집합으로 적용한다. 검색·필터 초기화로 원래 목록을 복원한다. 현재 불러온 목록만 검색하며 전체 이력 검색은 아니다. 원래 순서·평가 근거·서버 게이트 입력을 변경하지 않는다. 계정과 조직·프로젝트 범위가 바뀌면 조건을 초기화한다.

처리 상태는 대기·처리 완료·처리 실패를 구분한다. 처리 완료를 평가 통과나 릴리스 허용으로 표시하지 않는다. 평가·캠페인의 판정 요약은 필수 실패 수정, 근거/실행 상태 확인, 현재 게이트 재조회, 차단 사유/검토 확인 또는 릴리스 직전 재확인을 안내한다. 이 안내는 권한 부여나 배포 실행이 아니다.

이 변경의 완료 기준은 세 기능의 실제 화면 연결, 원본 보존·필터 교집합·권한 오해 방지 검사와 타입 검사다. 브라우저 시나리오를 확장하며 실제 브라우저·정확 리비전 CI·런타임 적용은 별도 결과로 기록한다.
