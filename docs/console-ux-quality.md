# 콘솔 UI/UX 품질 기준

## 최신 상태 — 2026-10-28

기존 4310 문서 제출 준비는 종료했다. 실제 영상·자막·노출 검토는 **미완료·보류**이며 제출처 규정에 맞춰 사용자가 추후 제작한다. 현재 촬영·입장 재실행·자동화 재개를 요구하지 않는다. [현재 제출 기준](portfolio-submission.md)과 [추후 영상 도구](portfolio-media-tools.md)를 따른다. 아래 새 스택·합성 UI 검토와 과거 일정은 보존 이력이며 4310 실제 수용 결과가 아니다.

상용 품질을 목표로 구현하되 자동 검사나 시안만으로 최고 수준 또는 접근성 인증 완료를 선언하지 않는다. 사용자가 평가를 찾고 근거를 확인한 뒤 다음 행동을 결정하는 흐름을 기준으로 판단한다.

## 이번 변경

- 데스크톱에서 업무 탐색을 옆에 유지하고 현재 위치를 표시한다. 작은 화면에서는 가로 탐색으로 전환한다. 기존 링크 이름과 URL 조각을 유지한다.
- 평가 판정과 현재 릴리스 판정을 분리하며 다음 행동을 전체 너비로 강조한다. 판정 실패·미확인을 허용으로 표현하지 않는다.
- 한글 시스템 글꼴과 여백·텍스트·테두리·버튼·입력·상태 배지의 시각 규칙을 통일한다. UI 검토용 CI에는 한글 산세리프 글꼴을 설치한다.
- 정확한 평가 ID 조회를 별도 시각 영역으로 묶고 진행 상태를 알린다. 기존 권한·조직 경계·서버 요청은 변경하지 않는다.
- 제품 화면의 기술 스택 설명은 제거하고 사용자에게 필요한 판정 의미를 남긴다. 개발 기술과 운영 제한은 문서에서 관리한다.

`scripts/console-ui-review.cjs`는 실제 WorkspaceNavigation·DecisionSummary·EvaluationIdLookup 컴포넌트와 실제 globals.css를 사용한다. 나머지 표·평가 목록은 공개 가능한 합성 fixture다. API·인증·DB·실제 평가와 연결하지 않으며 브라우저 네트워크를 차단한다. 이 경량 검토는 UI 구성요소·레이아웃 증거이며 실제 전체 업무 흐름이나 상용 수용의 대체 증거가 아니다. `--render-only`는 HTML 생성만 수행하며 브라우저 검토 통과를 뜻하지 않는다.

기존 d40cdd0 런타임·컨테이너·데이터·키·보존 가드는 변경하지 않는다. 이 개선은 PR10 위의 별도 개발 브랜치에서 검토하고, 병합·적용·상용 수용은 각각 별도 상태로 기록한다.

## 2026-10-27 작업 재개

[제출 후보 상태](portfolio-submission.md)를 따른다. 이번 승인 범위는 문서와 접근성 검토이며 PR 병합·런타임 적용은 포함하지 않는다. 실제 확대·스크린리더·사용자 과업은 여전히 미완료다. 정적 코드 검토와 합성 구성요소 검토를 실제 인증 UI 수용으로 기록하지 않는다.

수정 `f5cd9ff`는 320px 키보드 탐색에서 링크가 가려지는 문제를 해결한다. 로컬 전체 Workspace 격리 회귀와 타입·161 계약 검사, 수정 후 기본 CI·재실행 UI 검토·전체 통합 CI가 통과했다. 수정 후 실제 스택 E2E 개별 보고서에서 51개 통과·실패 0·건너뜀 0과 640/320px 탐색 시나리오 통과를 대조했다. 수정 전 `9927d77`의 결과와 구분한다. 최신 실제 스택·합성 화면과 공개 제한은 [시연 안내](portfolio-demo.md#수정-후-실제-스택-화면-공개-자료-후보)를 따른다.
