# 작업공간 공통 Top

2026-11-02 사용자 화면에서 사이드바의 `#overview` 등 구역 이동 시 기존 상단 전체가 스크롤 밖으로 사라지는 문제를 확인했다. 공통 상단을 `WorkspaceTop`으로 분리하고 작업공간 안에서 sticky로 유지한다. 서비스 제목·작업공간 제목·계정·로그아웃 및 Top 복귀를 제공한다. 공개 showcase와 구분되는 작업공간 공통 영역이며 별도의 독립 홈 URL을 추가한 것은 아니다.

구역 이동과 Top 복귀는 기존 문서 안의 anchor를 사용해 선택·입력·진행 중 요청을 재마운트하지 않는다. `ResizeObserver`로 실제 상단 높이를 측정하고 anchor 여백과 데스크톱 사이드바 위치에 반영한다. 작은 화면에서 메뉴는 기존처럼 본문 흐름에 두고 Top만 유지한다. 로그아웃은 기존 함수를 그대로 사용한다.

구성요소 화면 검사에는 실제 Top과 스타일을 사용한다. 네 화면 크기에서 이력 구역으로 이동한 뒤 상단이 뷰포트 안에 남는지, Top 복귀 시 제목이 가려지지 않는지 검사하고 별도 캡처를 남긴다. 실제 로그인된 탐색 검사에도 메뉴 이동 후 제목과 로그아웃의 뷰포트 잔류를 확인한다. 소스·CI 검증과 실제 운영 이미지 적용은 별도로 기록한다.
