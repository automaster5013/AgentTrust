# 평가·캠페인 취소

Next.js 콘솔 → WebFlux → Java API → PostgreSQL의 실제 취소 경로를 제공한다. 관리자는 같은 조직·프로젝트의 대기 평가를, 편집자는 자신이 생성한 평가를 취소할 수 있다. 조회자는 취소할 수 없다. 사유는 공백이 아닌 최대 200자다.

- `POST /api/runs/{id}/cancel`
- `POST /api/campaigns/{id}/cancel`
- 본문: `{ "reason": "취소 사유" }`; 로그인과 CSRF 토큰이 필요하다.

기존 대기 admission을 수정하지 않고 불변 완료 결과를 추가한다. 취소 결과는 `failed/inconclusive`, 실행 엔진은 서버 소유 `java-cancelled`다. OPA의 현재 릴리스 게이트는 허용하지 않는다. 같은 취소 요청을 반복해도 결과와 감사 이벤트를 중복 생성하지 않는다. 정상 완료된 평가의 취소는 409다.

캠페인은 부모 잠금과 정렬된 자식 완료 잠금을 잡고 미완료 사례만 원자적으로 취소한다. 이미 완료된 자식 결과·버전·근거를 보존한다. 워커 완료와 취소는 같은 완료 잠금을 사용하며, 취소 후 도착한 유효한 완료 요청은 중복으로 인정해 저장된 취소 판정을 덮어쓰지 않는다. 워커는 `java-cancelled` 결과를 제출할 수 없다.

모델 예약 역시 완료 잠금을 사용한다. 취소가 먼저 확정된 평가에는 새 공급자 예산을 예약하지 않는다. 이미 시작된 외부 모델 호출을 즉시 중단하는 기능은 아니며, 이미 예약한 사용량을 환불하지 않는다. 취소 결과도 기존 MinIO 보관·유사 근거 인덱싱 경로의 대상이다.

`scripts/stack-cancellation-smoke.py`는 자체 생성한 합성 사례로 실제 OIDC/BFF/WebFlux/Java/DB의 권한·반복 취소·늦은 완료·예산 예약 차단·캠페인 완료 자식 보존을 검사한다. 테스트 중 전용 Python 워커를 잠시 정지하고 `finally`에서 복구하며, 자신의 로그인 세션을 종료한다. 늦은 콜백은 프로토콜 검증용 합성 입력이다. 유료 모델 호출이나 기존 업무 데이터 변경은 수행하지 않는다.

2026-10-11 로컬 검증: Java 68개, 게이트웨이 16개, TypeScript 38개 테스트 및 Next.js 빌드 통과. 실제 취소 통합 5개 검증과 브라우저 취소 1개 검증, 기존 현재 판정 브라우저 2개 회귀 검증이 통과했다. CI 결과는 해당 커밋의 GitHub Actions 실행에서 별도로 확인한다.
