# 완료 평가의 관측 결과 JSON 저장

4310의 선택된 완료 평가 `결과 JSON 저장` 작업을 4320의 평가 근거 화면에 연결한다. 조회자도 기존 인증된 `GET /api/runs/{id}`의 읽기 권한으로 사용할 수 있다. 명시적 클릭 후 결과를 새로 읽고, 현재 선택한 평가의 ID·조직·프로젝트·공급자·시나리오·상태·생성 시각·규칙 내용 전체가 화면의 검증된 관측과 일치할 때만 파일 저장을 요청한다.

파일은 `completed-evaluation-observation` 형식의 최대 512KiB JSON이다. 기존 `detail` 계약으로 검증하고 허용한 화면 관측 필드만 포함하며 원래 DB·HTTP 응답의 정확한 바이트 사본은 아니다. 추가 응답 필드, 현재 게이트, 관리자 검토 및 서명 토큰은 포함하지 않는다. `historicalEvidenceOnly=true`, `deploymentAuthority=false`, `signed=false`, `currentGateIncluded=false`를 명시한다. 과거 pass 결과가 현재 배포 허용을 뜻하지 않는다.

queued 평가, 범위·선택·관측 내용 불일치, 읽기 실패에는 파일을 만들지 않는다. 취소·다른 평가 선택·사용자 범위 변경 후 늦게 도착한 응답도 무시하며 임시 Blob URL은 정리한다. 업무 쓰기·평가 생성·검토 변경이나 자동 재시도는 없다.

이 파일은 MinIO 보관 근거, 원본 바이트 해시, 독립 서명 검증 또는 현재 게이트를 대체하지 않는다. 새 API 쓰기나 DB 스키마·계정·인증 설정 변경 없이 기존 읽기 계약을 재사용한다. 실제 서비스와 원본에는 적용하지 않으며 소스·합성 구성요소 검증과 실제 후보 API·파일 다운로드 수용 결과를 구분한다.
