# AgentTrust — 평가 근거와 릴리스 판단을 연결하는 제품

제출 대상은 기존 JavaScript 제품인 로컬 4310 설치다. 기업 개발팀이 에이전트 평가 결과의 근거를 확인하고, 평가 통과와 릴리스 허용을 구분하도록 돕는다.

## 핵심 흐름

1. 조회자 권한으로 기존 프로젝트와 실행 기록을 확인한다.
2. 실행에 연결된 버전·규칙별 판정·근거를 읽는다.
3. 승인·반려 검토 이력을 확인하고 평가 결과와 관리자 판단을 구분한다.
4. 보관된 서명 기록의 무결성과 현재 릴리스 권한이 서로 다른 의미임을 확인한다.

평가 통과는 기본적인 필요 조건이며, 현재의 검토 상태·유효성·근거를 확인하는 릴리스 판단을 대신하지 않는다. 과거에 서명된 기록이 있다는 사실도 현재 배포 권한을 보장하지 않는다.

## 구현과 검증 범위

기존 설치의 JavaScript 화면·API·작업 실행기와 PostgreSQL 업무 경로를 설명한다. 읽기 전용 API 로그인, 기존 실행·검토 이력·서명 기록 조회와 로그아웃은 확인됐다. 실제 과거 기록의 서명은 보존된 독립 신뢰 공개키로 검증했고, 승인·반려 이력 두 건의 본문 해시와 실행·범위 결합도 확인했다.

선택한 화면 처리·권한·기록 검사 274개와 추가 서명·근거 검사 14개가 기존 검증 기록에서 통과했다. 이 수치는 특정 범위의 검증이며 전체 상용 수용이나 현재 브라우저의 접근성 통과를 뜻하지 않는다.

## 현재 제한

- 기존 4310의 실제 브라우저 핵심 흐름, 200%·400% 확대와 Narrator 청취는 최종 수용되지 않았다.
- 실제 시연 영상은 제출처 규정에 맞춰 추후 직접 제작한다. 실제 영상·자막·노출 검토는 미완료·보류이며 현재 제출 문서에는 포함하지 않는다.
- 실제 고객 파일럿, 운영 인증·키 수명주기, 고가용성, 운영 부하 목표와 복구시간 보장은 제출 성과에 포함하지 않는다.
- 새 스택·새 UI의 CI와 화면, 합성 자막은 이번 4310 제출의 증거로 합산하지 않는다.
- 로컬에 추가한 배포 사전검사 보완은 미적용 수정이며, 현재 실행 제품의 적용 성과로 주장하지 않는다.

## 설계 선택

판정과 근거를 불변 버전에 연결하고, 필수 실패·실행 오류·증거 누락을 통과로 해석하지 않는다. 조회 권한과 관리자 검토 권한을 구분하며, 검증 기록을 현재 권한과 혼동하지 않도록 한다. 이번 시연은 기존 기록을 읽는 범위로 제한해 업무 데이터 생성이나 배포를 수행하지 않는다.
