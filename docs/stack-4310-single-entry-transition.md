# 폐기된 4310 단일 진입점 제안

2026-10-31 사용자 정정으로 이 문서의 기존 4310 주소 인계 계획을 폐기한다. **최종 플랫폼은 4320**이며 원래 기술 스택인 Next.js/TypeScript, Java/Spring Boot, Python/FastAPI로 구현한다.

4310은 기존 JavaScript 구현·자료·비교 기준으로 보존한다. 4310 포트 인계, 새 local-single-entry OIDC 프로필, IdP의 /identity prefix 전환, 기존 서비스의 중지·재생성은 현재 목표가 아니다.

현재 계획은 [4320 통합 플랫폼 구현 계획](stack-4320-integrated-platform.md)을 따른다. 데이터·계정·서명 자동 이전 금지, 실제 복구·CD 검증과 서비스 보존 조건은 유지한다.
