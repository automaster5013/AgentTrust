# 새 스택의 기능 이전 범위

2026-10-11의 기술 전환은 기존 v0.187의 모든 기능을 이전했다는 뜻이 아니다. Java/Python/TypeScript 서비스가 실제 요청을 처리하는 첫 통합 흐름을 구축하고, 각 기술의 사용 경로를 검증했다. 기존 JavaScript 기능과 데이터는 비교 기준으로 보존한다. 언어 비율이나 기존 테스트 수는 새 구현의 완성도를 나타내지 않는다.

2026-10-11에는 [버전과 캠페인](stack-campaigns.md)의 실제 API·Python 실행·승인/반려·같은 데이터셋의 제한된 회귀 비교와 브라우저 흐름을 로컬 검증했다. 필수 실패/누락/오류, 치환된 완료 결합, 워커 복구와 늦은 완료를 검사한다. 이 범위는 범용 품질 평가나 회귀 기준을 필수로 하는 최종 정책의 이전 완료가 아니다. 버전 결합을 포함한 부모/자식 보관 증거의 로컬 검증도 추가했다. 개발용 과거 판정 서명까지 추가했으며, 이후 운영 신뢰키·현재 배포 토큰·운영 인증·복구를 이전한다. 배포 대상이 정해지기 전에는 운영 배포 완료로 표시하지 않는다.

새 기능은 실행 요청부터 저장된 근거와 현재 게이트까지 하나의 실제 기능 경로를 통과해야 완료로 기록한다. 서비스 파일이나 의존성만 추가한 상태는 계획/준비 상태로 표시한다. 기술 대체·제외는 사용자 합의 없이 하지 않는다.

2026-10-12 로컬에서는 [비교 기준에 묶인 게이트](stack-baseline-gate.md)의 실제 생성·평가·승인·현재 서명과 자연 만료를 검증했다. 이 기능의 CI 및 게시 이미지 증거는 해당 소스 revision의 실행 결과로 별도 기록한다.

2026-10-12 로컬에서는 [감사 메타데이터 내보내기](stack-audit-export.md)의 실제 읽기 전용 경로·500개 제한·RLS·바이트 hash·브라우저 다운로드와 변조 거부를 검증했다. 파일은 독립 감사 서명이 아니며 운영 배포 권한을 부여하지 않는다.

2026-10-12 로컬에서는 [양쪽 근거 번들](stack-baseline-bundle.md)의 실제 Java v3 서명·MinIO 부모/자식 바이트·독립 공개키와 실제 비교 재계산을 검증했다. 기준 게이트 6개·취소된 기준 2개 검사 묶음, 만료/취소 기준 각각의 오프라인 거부 6개와 전체 브라우저 22개 검사가 통과했다. CI 및 정확한 게시 이미지 검증은 별도로 확인한다.

2026-10-12 로컬에서는 [불변 버전 폐기](stack-version-lifecycle.md)의 후보·기준 에이전트와 데이터셋 네 경로, 권한·RLS·과거 내용 보존·현재 서명 차단·폐기 전후 독립 공개키 번들 검증 및 브라우저 선택/실행 거부를 검증했다. 운영 배포나 버전 자동 유효 기간을 구현한 것으로 표시하지 않는다. CI와 정확한 게시 이미지의 결과는 해당 revision에서 별도 확인한다.

2026-10-12 로컬에서는 [작업과 대상별 감사 검색](stack-audit-search.md)의 실제 Java/PostgreSQL/Keycloak 조회, 조건·조직에 묶인 탐색, 변조 응답 거부와 브라우저 검색을 검증했다. 기존 업무 데이터와 감사 내보내기는 보존하며 CI 및 게시 이미지 증거는 별도 확인한다.
