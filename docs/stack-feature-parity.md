# 새 스택의 기능 이전 범위

2026-10-11의 기술 전환은 기존 v0.187의 모든 기능을 이전했다는 뜻이 아니다. Java/Python/TypeScript 서비스가 실제 요청을 처리하는 첫 통합 흐름을 구축하고, 각 기술의 사용 경로를 검증했다. 기존 JavaScript 기능과 데이터는 비교 기준으로 보존한다. 언어 비율이나 기존 테스트 수는 새 구현의 완성도를 나타내지 않는다.

2026-10-11에는 [버전과 캠페인](stack-campaigns.md)의 실제 API·Python 실행·승인/반려·같은 데이터셋의 제한된 회귀 비교와 브라우저 흐름을 로컬 검증했다. 필수 실패/누락/오류, 치환된 완료 결합, 워커 복구와 늦은 완료를 검사한다. 이 범위는 범용 품질 평가나 회귀 기준을 필수로 하는 최종 정책의 이전 완료가 아니다. 버전 결합을 포함한 부모/자식 보관 증거의 로컬 검증도 추가했다. 개발용 과거 판정 서명까지 추가했으며, 이후 운영 신뢰키·현재 배포 토큰·운영 인증·복구를 이전한다. 배포 대상이 정해지기 전에는 운영 배포 완료로 표시하지 않는다.

새 기능은 실행 요청부터 저장된 근거와 현재 게이트까지 하나의 실제 기능 경로를 통과해야 완료로 기록한다. 서비스 파일이나 의존성만 추가한 상태는 계획/준비 상태로 표시한다. 기술 대체·제외는 사용자 합의 없이 하지 않는다.

## 평가 이력의 현재 페이지 필터 — 2026-10-24

Next.js 평가 이력에 판정(통과·차단·판정 불가)과 공급자를 함께 적용하는 읽기 전용 필터를 추가했다. 이미 조직·프로젝트·순서·커서를 검증한 현재 페이지의 최대 25개만 대상으로 하며, 전체 이력 검색이나 서버 필터를 구현한 것은 아니다. 필터는 페이지 이동 중 유지되고 해제하면 현재 페이지의 전체 행을 다시 표시한다. 일치하는 행이 없어도 원래 다음 커서는 유지하므로 다른 페이지로 이동할 수 있다. 원래 빈 페이지와 필터 결과 없음의 안내를 구분한다. 평가 판정은 현재 릴리스 권한을 부여하지 않는다.

로컬 계약 검사와 TypeScript 검사 결과는 해당 변경의 검증 기록을 따른다. 실제 브라우저 회귀 시나리오를 확장했지만 현재 보존 중인 서비스에는 변경을 적용하지 않았고 브라우저 실행·게시 이미지·상용 수용은 별도 미검증이다. 범용 필터·회귀 탐색·의미 검색의 전체 이전 완료로 계산하지 않는다.

### 캠페인 이력의 현재 페이지 필터 — 2026-10-24

조직·프로젝트 및 데이터셋 범위 검증을 마친 최대 25개 캠페인 요청에서 승인 필요 설정과 고정 에이전트 버전을 함께 필터링한다. 페이지 이동 시 조건을 유지하며, 숨겨진 행이 있어도 원래 커서와 페이지 이동을 보존한다. 필터 해제와 일치 항목 없음 안내를 제공한다. 승인 필요 설정은 요청 당시 값이며 현재 승인 여부나 완료 상태가 아니다. 근거 열기와 비교 기준 선택 후에는 기존 API가 범위·완료·비교 적합성을 다시 검증한다.

전체 이력 검색과 서버 필터는 미구현이다. 이 기능만으로 캠페인 근거 탐색 전체나 상용 게이트 완료를 주장하지 않는다. 실제 브라우저 수용 및 실행 중 환경 적용은 별도 검증 대상이다.

### 캠페인 사례 근거 필터 — 2026-10-24

범위를 검증한 단일 캠페인의 사례 표에서 필수·선택 여부와 판정을 함께 좁혀 볼 수 있다. 전체/표시 사례 수, 일치 항목 없음, 필터 해제를 제공하고 캠페인을 바꾸면 조건을 초기화한다. 표시 필터는 전체 사례나 집계 판정·검토·보관 검증·릴리스 게이트 입력을 변경하지 않는다. 대기·오류의 판정 불가를 통과로 취급하지 않는다. 브라우저 수용과 실행 환경 적용은 별도 미검증이며 범용 회귀 탐색 전체 완료가 아니다.

사례 근거 필터에 실행 상태(대기·완료·실패)를 추가했다. 판정과 독립적으로 조합하며 실행 완료가 판정 통과를 뜻하지 않는다. 대기 및 실패의 판정 불가를 구분할 수 있다. 전체 판정과 게이트 입력은 계속 전체 사례를 사용한다.


### 평가 이력의 승인 필요 설정 필터 — 2026-10-25

범위와 순서를 검증한 현재 페이지에서 요청 당시 관리자 승인 필요 여부를 판정·공급자·실행 상태와 함께 필터링한다. 표에 승인 필요 설정을 표시하고, 현재 승인·반려 상태나 배포 허용과는 구분한다. 페이지 이동 시 조건을 유지하며 해제하면 현재 페이지 전체 행이 복원된다. 전체 이력 검색이나 서버 필터는 아니다. 로컬 계약·타입 검사와 브라우저 시나리오를 준비했으며 실제 브라우저 수용 및 실행 환경 적용은 별도 미검증이다.
