# 새 스택의 기능 이전 범위

2026-10-10의 기술 전환은 기존 v0.187의 모든 기능을 이전했다는 뜻이 아니다. Java/Python/TypeScript 서비스가 실제 요청을 처리하는 첫 통합 흐름을 구축하고, 각 기술의 사용 경로를 검증했다. 기존 JavaScript 기능과 데이터는 비교 기준으로 보존한다. 언어 비율이나 기존 테스트 수는 새 구현의 완성도를 나타내지 않는다.

| 기능 계약 | 새 스택에서 실제 검증한 범위 | 남은 이전 작업 |
|---|---|---|
| 조직·역할·인증 | Keycloak OIDC·PKCE·조직/프로젝트 RLS·관리자/편집자/조회자·로그아웃/세션 철회 | 동적 기업 조직/프로젝트 등록, 운영 IdP·키 교체·공개 HTTPS 구성 |
| 에이전트·데이터셋·정책 버전 | 에이전트·고정 시나리오 데이터셋의 불변 등록/조회·SHA-256·캠페인/워커 결합, OPA 정책 버전·해시 검토 결합 | 범용 에이전트·프롬프트·품질 데이터셋, 모든 공급자 프로필 내용의 불변 버전 |
| 평가 실행 | 네 고정 시나리오·Python/NATS 영속 실행, 불변 버전 캠페인의 다중 사례·멱등 admission·집계·기한/워커 복구 | 범용 데이터셋 실행, 동적 병렬 작업 분배 |
| 모델 공급자 | 실제 고정 Ollama와 로컬 OpenAI 호환 추론·1회 예약·조직·프로젝트 조합별 100회/UTC일 한도·시간/출력 제한 | 실제 OpenAI 계정 검증, 외부 호환 서버의 운영자 설정, 가격별 비용/사용량 정산 |
| 평가 검증 | 실제 Promptfoo의 네 합성 사례·여덟 단언 | 일반 모델 품질·안전성 데이터셋과 자체 평가기의 결과 비교 |
| 근거 탐색 | 결과·공급자/engine·규칙·원본 출력 hash·pgvector 규칙 특징 코사인 이웃 | 같은 버전 캠페인 사례 조회·회귀 상태 비교를 제외한 기존 필터·회귀 탐색·AI 의미 임베딩 |
| 관리자 검토·현재 게이트 | 단일 평가 및 다중 사례 캠페인의 승인 필요·승인·최신 반려·실패/누락/기한 차단·정책 결합 | 기존 비교 기준과 버전 유효 기간을 포함한 전체 게이트 계약 |
| 보관 근거 | MinIO의 정확한 바이트 hash·고정 버전 조회·조직 경계·7일 COMPLIANCE 잠금 | 운영 보존 정책, 대량 export, 기존 서명 기록과의 이전 계약 |
| 서명·오프라인 증거 | 이미지 공급망 서명과 SBOM attestation을 검증하는 CI | 새 Java 평가 게이트의 Ed25519 서명·신뢰키·오프라인 현재/과거 의미 분리 |
| 운영·배포 | 로컬 Compose·장애 복구·Redis 한도·관측성·검토용 Helm/Terraform 검증 | 지정 클러스터, stateful 서비스/백업·복구·HA·외부 TLS·실제 배포/복귀 |

2026-10-11에는 [버전과 캠페인](stack-campaigns.md)의 실제 API·Python 실행·승인/반려·같은 데이터셋의 제한된 회귀 비교와 브라우저 흐름을 로컬 검증했다. 필수 실패/누락/오류, 치환된 완료 결합, 워커 복구와 늦은 완료를 검사한다. 이 범위는 범용 품질 평가나 회귀 기준을 필수로 하는 최종 정책의 이전 완료가 아니다. 이후 버전 결합을 포함한 보관 증거와 서명 게이트, 운영 인증·복구를 이전한다. 배포 대상이 정해지기 전에는 운영 배포 완료로 표시하지 않는다.

새 기능은 실행 요청부터 저장된 근거와 현재 게이트까지 하나의 실제 기능 경로를 통과해야 완료로 기록한다. 서비스 파일이나 의존성만 추가한 상태는 계획/준비 상태로 표시한다. 기술 대체·제외는 사용자 합의 없이 하지 않는다.
