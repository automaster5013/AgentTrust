# 불변 버전의 전체 고정 정의 확인

4310의 `version-inspection-output`은 선택한 버전의 목록 좌표·내용 해시를 확인한 뒤 고정 정의 JSON을 보여 준다. 이 작업을 4320 통합 카탈로그의 검증 상세에 연결한다. 기존 인증된 `GET /api/versions/{agents|datasets}/{id}`를 재사용하며 조회자도 읽을 수 있고 업무 쓰기는 없다.

조직·프로젝트, 버전 ID·이름·번호·정확한 생성 시각과 SHA-256을 확인한 후에만 **고정 정의 펼치기**를 제공한다. 에이전트는 고정 실행 프로필과 프로필 해시를 포함한 전체 검증 정의, 데이터셋은 현재 지원 계약의 전체 사례 정의를 표시한다. 메타데이터 응답의 다른 필드나 미검증 원문은 표시하지 않는다. 고정 정의는 최대 16KiB이며 기존 계약의 내용·개수 제한도 유지한다.

JSON은 React 텍스트로 표시하며 HTML·스크립트·설정으로 실행하지 않는다. 펼치기 전에는 정의 내용을 렌더링하지 않고 접으면 제거한다. 목록 재조회, 다른 버전 선택, 종류·이름 필터 변경, 오류 및 사용자 범위 변경 시 이전 정의와 펼침 상태를 제거하고 늦은 응답을 버린다. 좁은 화면에서는 긴 값과 JSON을 줄바꿈한다.

정책 버전 관리, 동적 공급자 설정, 과거 4310 자료 연결이나 현재 배포 권한 이전은 이 범위에 포함하지 않는다. 정의를 보는 것만으로 등록·활성화·평가·승인을 수행하지 않는다. 실제 서비스·원본·DB 스키마·계정·인증 설정은 변경하지 않는다. 소스 및 합성 브라우저 검증과 실제 후보 API·브라우저 CI 수용 결과는 구분해 기록한다.
