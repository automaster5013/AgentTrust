# 위협 모델

## 현재 구현과 제품 목표의 구분 — v0.95

이 문서는 아래 초기 통제 설계와 현재 프로토타입을 구분한다. 실제 고객 데이터·모델 API 키·OIDC 제공자·배포 서버는 연결하지 않았다. 현재 검증은 합성 데이터와 모의 어댑터, 로컬 API/워커, 격리 테스트 DB와 CI 이미지 실행에 한정한다.

| 경계 | 현재 코드와 검증 | 아직 필요한 운영 통제 |
|---|---|---|
| 인증·권한 | 해시로 저장한 로컬 접근 키·세션·프로젝트 범위 CI 키, 역할 검사, 만료·철회 재검증, 세션 관리 | 기업 OIDC/SSO·멤버 수명주기·2인 승인. 현재 관리자의 본인 실행 승인은 허용한다. |
| 조직·프로젝트 데이터 | API 범위 검사, API DB 역할의 RLS, 불변 버전·실행 근거, 다른 조직/프로젝트 접근 거절 테스트 | 객체 저장소·단기 서명 파일 URL. 워커는 제한된 별도 BYPASSRLS 역할이다. |
| 비밀·원문 | 런타임 역할별 DB 자격, API 전용 서명 키, Git 제외 `.env`/`.local`, 고정 실패 출력과 합성 canary 테스트 | 외부 비밀 저장소·회전 운영·고객 원문 마스킹/삭제 정책. 로컬 설정 파일은 애플리케이션 수준에서 암호화하지 않는다. |
| 브라우저·응답 | CSP, 텍스트 렌더링, loopback/Origin 검사, UI HTTP deadline와 범위 보호, 브라우저·시연 명령의 엄격한 UTF-8/8 MiB 읽기 | 고객 환경의 브라우저·프록시·TLS 운영 검증. JSON 내보내기만 지원하며 CSV 수식 무력화를 구현했다고 주장하지 않는다. |
| 외부 어댑터·코드 | 임의 코드 실행 금지, HTTPS 어댑터의 허용 대상·주소·리디렉션 검증 테스트, Compose 워커의 내부 네트워크 | 실제 고객 모델 연동과 egress 프록시. 현재 Compose 구성에서 외부 모델 연결을 검증하지 않았다. |
| 자원·큐·복구 | 입력/결과 한도, 쿼터·시간/사례 예산·시도 제한, lease fencing, 멱등 계량, 암호화 백업과 격리 복원 | 상용 SLA/RPO/RTO·다중 워커 처리량·실제 과금/토큰 계량·운영 장애 절차 검증. |
| 전달·출처 | 고정 의존성과 audit, 네 CI 작업, 정확한 registry digest 실행 뒤 승격, 전달 파일 checksum과 온라인 CI 성공 조회 | 서명된 이미지 attestation·웹훅 인증·별도 staging·운영 서버 배포. checksum과 성공 조회는 출처 서명 인증이 아니다. |

현재 통제의 근거는 [기술 설명](portfolio-engineering.md), [시연](portfolio-demo.md), [전달 검증](github-delivery.md)에서 확인한다. 아래 표의 객체 URL·OIDC·egress 프록시·외부 비밀 저장소·웹훅 통제는 초기 제품 목표다. 구현 목록으로 사용하지 않는다.

## 자산과 신뢰 경계

보호 자산: 고객 데이터, 모델 API 키, 평가 증거, 승인 정책, 계정, 사용량·과금 기록.
공격자: 외부 공격자, 악성 조직 사용자, 탈취 계정, 악성 평가 대상, 인젝션을 포함한 데이터셋·도구 출력.
경계: 브라우저→API, API→DB/작업 큐, 작업 큐→워커, 워커→평가 대상/모델, 실행 환경→외부 네트워크, 고객 조직 간 경계.

에이전트 출력·평가 파일·외부 문서는 전부 비신뢰 데이터다. 그 안의 지시를 플랫폼 권한이나 운영 명령으로 해석하지 않는다.

| 위협 | 통제 설계 | 필수 검증 |
|---|---|---|
| 조직 간 결과/파일 접근 | 서버에서 조직 범위 적용, DB 행 정책을 방어층으로 사용, 객체 URL 단기 서명 | 다른 조직의 ID로 조회·수정·다운로드 거절 |
| 인젝션을 통한 도구 권한 초과 | 모의 도구 기본값, 명시적 도구/인자 정책, 외부 부작용 금지 | 금지 도구·인자 호출 차단과 증거 기록 |
| URL 어댑터의 SSRF | HTTPS 허용목록, 사설/루프백/메타데이터 주소 거절, 리다이렉트 통제, 실제 연결 주소 검증, egress 프록시 | IPv4/IPv6·DNS 재바인딩·리다이렉트 우회 검사 |
| 원격 코드 실행과 탈출 | MVP 임의 코드 실행 금지; 이후 별도 격리 실행 계층, 권한·파일·자원·네트워크 제한 | 전문 검토와 탈출 테스트 완료 전 활성화 금지 |
| 비밀 유출 | 외부 비밀 저장소, 최소 권한·짧은 수명 자격, 로그 마스킹, 민감 원문 접근 제한 | 합성 canary가 로그/내보내기에 나타나지 않음 |
| 결과/정책 조작 | 버전 불변성, 실행 스냅샷, 결과 해시, 정책 변경 감사 | 변경된 정책·증거로 과거 판정이 바뀌지 않음 |
| 출력 기반 XSS/CSV 수식 | 출력 텍스트 렌더링, HTML 금지, 내보내기 수식 무력화 | 스크립트와 수식 입력이 실행되지 않음 |
| 비용 폭주/서비스 거부 | 조직별 쿼터, 실행 예산, 동시성·크기·시간 제한, 제한적 재시도 | 무한 호출/대형 입력/취소 시 예산 경계 확인 |
| 큐 중복/오래된 결과 | 멱등성 키, 상태 전이 원자성, 시도별 식별자 | 중복 전달이 중복 과금·판정을 만들지 않음 |
| 계정 탈취/권한 상승 | OIDC 세션 검증, 역할 검사, 관리자 작업 감사, API 키 해시 저장 | 조회자가 정책·키·멤버를 변경할 수 없음 |
| 웹훅 위조/공급망 공격 | 서명·타임스탬프·재전송 검사, 종속성 고정과 취약점 검사 | 변조·재전송 거절, 빌드 아티팩트 추적 가능 |

## 남는 위험과 운영 대응

테스트에 없는 공격, 모델 변경과 비결정성, 마스킹 누락, 클라우드 제공자 장애는 남는다. 통과 판정에는 테스트·정책·버전·시간·제약을 함께 표시한다. 평가 결과만으로 규제 준수나 무결한 안전을 주장하지 않는다.

사고 대응: 접근/실행 차단 → 증거 보존 → 영향 조직·데이터 확인 → 자격 증명 회전 → 고객 통지 판단 → 복구 검증 → 재발 방지. 보존 기간과 통지 의무는 계약·배포 지역 검토로 확정한다.

로그에 원문 프롬프트와 응답을 기본으로 남기지 않는다. 원문 증거 저장을 허용할 때는 고객 동의, 암호화, 접근 기록과 삭제 정책을 적용한다.
