# 단계별 로드맵과 출시 조건

일정은 2~3명의 개발자와 보안 검토 지원을 가정한 추정이며 인력·고객 요구·실측에 따라 조정한다. 각 단계는 날짜보다 완료 조건을 우선한다.

| 단계 | 예상 기간 | 결과 | 완료 조건 |
|---|---|---|---|
| 0. 제품 기준선 | 현재~1주 | 범위·위협·아키텍처·고객 가설 | 첫 고객, 데이터 민감도, 배포 요구 정리 |
| 1. 평가 수직 구현 | 1~2주 | 모의 에이전트→규칙→게이트→결과 화면 | 고정 샘플의 통과·실패·오류 재현, 버전 스냅샷 |
| 2. MVP 보안·운영 | 2~3주 | 인증·조직 격리·비동기 큐·감사·예산 | 조직 간 접근 거절, 취소·중복·복구 검증 |
| 3. 제한된 파일럿 | 2~4주 | 통제된 원격 어댑터·비교·CI 연동 | 승인된 대상의 네트워크 경계 검증, 고객 흐름 검증 |
| 4. 상용화 준비 | 3~5주 | SSO·계량·보존·백업·운영·보안 검토 | 아래 출시 게이트 충족 |

기간은 보장이 아니다. 실제 임의 코드 실행이 필요하면 독립 샌드박스 설계·검증 일정을 추가한다.

## 상용화 배포 전 게이트

- 제품: 고객의 대표 워크플로가 문서화되고 파일럿에서 반복 검증됨. 가격·지원·사용 제한·데이터 처리 조건 확정.
- 정확성: 정책/데이터/에이전트 버전으로 결과 추적 가능. 시간 초과·증거 누락·판정 오류가 통과하지 않음.
- 보안: 조직 격리·RBAC·비밀·SSRF·출력 렌더링·샌드박스(해당 시) 검증 완료. 알려진 중대 취약점은 해결 또는 승인된 제한으로 비활성화.
- 운영: 부하 목표를 설정하고 측정. 제안 초기 목표는 동시 20개 실행과 메타데이터 API p95 500ms 이하이며 모델 지연은 분리 측정.
- 복구: 백업으로 실제 복원 훈련. 초기 RPO 24시간/RTO 4시간은 제안값이며 계약 전 검증·확정.
- 데이터: 보존·삭제·내보내기·하위 처리자·리전 결정과 고객 고지 검토 완료. 데이터 종류와 지역에 맞는 전문 검토 수행.
- 배포: 스테이징 검증, 마이그레이션·롤백 훈련, 관측성·온콜·사고 대응 담당자 확정.

## 범위 관리

새 기능은 고객 시나리오, 위험 통제 또는 출시 조건에 연결해야 한다. 범용 에이전트 빌더, 모델 학습, 마켓플레이스는 초기 범위 밖이다. 공격 데이터셋은 출처·이용 조건·민감 정보 검토 후 채택한다.

## 포트폴리오 집중 개발 목표 — 6~8주

사용자 요청에 따라 상용화 로드맵과 별도로 기업 개발팀의 평가 실행·릴리스 승인 시연을 우선한다. 기간은 목표이며 실행되는 개발 시간과 검증 결과에 따라 조정한다.

| 기간 | 핵심 결과 | 완료 조건 |
|---|---|---|
| 1~2주 | 평가→근거→검토→최종 게이트 경험 | 합성 통과·차단·오류와 승인 만료를 재현하고 다음 행동을 화면에서 파악 |
| 3~4주 | 권한·실패·복구 및 핵심 화면 완성 | 조직 경계와 권한별 시나리오, 취소·복구 검증 |
| 5~6주 | 재현 가능한 데모와 기술 설명 | 설치·시연·아키텍처·검증 범위를 저장소에서 따라 실행 |
| 7~8주 | 최종 점검과 공개 자료 | 사용자 흐름 점검·결함 수정·시연 자료 완성 |

기능 추가는 핵심 시연이나 명확한 위험 통제에 연결한다. 실제 고객 연동·SSO·상용 운영은 해당 환경과 요구가 확정된 뒤 별도 범위로 다룬다.
