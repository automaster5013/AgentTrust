# 캠페인 회귀 원인 탐색

검증된 후보·기준 비교 결과에서 새 필수 실패·미확인 필수 사례·개선된 필수 사례를 선택하고 사례 ID로 검색한다. 검색어는 최대 64자이며 앞뒤 공백·영문 대소문자를 무시한다. 각 분류의 표시 수와 원래 수를 함께 표시하며 초기화로 복원한다. 원래 비교 판정·근거·권한은 변경하지 않는다.

후보/기준 근거 열기는 검증된 비교 응답에 결합된 캠페인 ID만 기존 인증·범위 검증 조회 경로로 전달한다. 이 이동은 읽기 전용이며 새 평가·승인·게이트 권한을 만들지 않는다. 기준 변경으로 비교 화면이 교체되면 필터도 초기화한다.

타입·단위 검사와 브라우저 시나리오를 포함한다. 실제 브라우저 수용·정확 리비전 CI·런타임 적용은 별도 검증 대상이다.
