# 첫 평가 흐름 검증 기록

검증일: 2026-10-03 (Asia/Seoul). 작업 루트: C:\AgentTrust.

## 자동 검증

Node.js 24.15.0 / Windows에서 npm run check와 npm test를 실행했다. 17개 테스트가 모두 통과했다.

평가 코어: 정상·회귀·금지 도구·실행 오류·누락 증거·스크립트 출력, 도구 인자 제한, JSON 불일치, 오류와 필수 실패의 판정 우선순위, 스키마/입력 거절.
상태와 버전: 생성 후 입력/조회 복제본/새 버전 변경이 실행 스냅샷을 바꾸지 않음, 같은 멱등성 키와 다른 JSON 키 순서도 동일 실행을 반환함, 다른 본문 재사용 거절, 중복 실행 확정 방지, 메모리 한도.
HTTP: 데이터셋 등록부터 6개 모의 모드 실행·결과·게이트 조회, cross-origin/잘못된 Host/잘못된 JSON/헤더 누락/대형 본문/비허용 파일 경로 거절, CSP와 텍스트 렌더링 경로.

npm audit에서 처음 발견된 Ajv 경고를 8.20.0으로 교체했고 교체 후 알려진 취약점 0건을 확인했다. 감사 결과는 검사 당시 공개된 취약점 데이터 기준이다.

## 실제 브라우저 검증

로컬 in-app 브라우저에서 정상 평가 PASS, 금지 도구 BLOCK, 실행 오류 INCONCLUSIVE와 배포 허용 안 함을 확인했다. 스크립트 포함 출력은 문자 그대로 표시됐고 결과 DOM에 script 요소가 0개였다. JSON 데이터셋을 새 버전으로 등록하고 선택 목록 반영을 확인했다.

최종 서버를 재시작하고 정상 평가를 다시 실행해 PASS를 확인했다. [결과 화면](evidence/local-evaluation.jpg)을 저장했다. 기본 브라우저 폭에서 좁은 화면 레이아웃을 육안 확인했다. 모든 브라우저/해상도에 대한 호환성 검증은 아직 수행하지 않았다.

## 미검증 영역

GitHub 원격 CI 실행, 운영 배포, 인증/조직 경계, DB/실제 큐 복구, 취소/시간 예산, 외부 모델과 샌드박스는 이번 범위 밖이다. 로컬 데모 테스트 결과를 상용 보안 인증으로 해석하지 않는다.
