# 기록된 합성 도구·JSON 규칙 평가 — 후보 수용 대기

2026-11-12 22:15 KST 기준, 새 `recorded-connector-rules-v1` 계약의 소스를 개발 사본에서 구현했다. 최종 커밋·후보 CI 수용 전이며 현재 복구 4320에는 적용하지 않았다. [선행 계약](stack-recorded-connector-rules-design.md)을 따른다.

기존 등록·캠페인·완료 인증과 RLS를 사용한다. 새 독립 초안에서 에이전트와 데이터셋을 각각 명시 등록하고 기존 캠페인 선택·실행을 사용하도록 연결했다. 원래 예제 두 사례의 다섯 규칙을 포함한다. `contains`, `not_contains`, `allowed_tools`의 선택 인자 스키마, `json_schema`를 지원하며 스키마는 평면 문자열 객체로 제한한다. null 미관측과 빈 출력·빈 도구 배열을 구분한다. 실제 도구 호출이나 연결 권한을 제공하지 않는다.

새 Python 평가·소비자·준비 상태와 새 Node 내부 검증 경로를 작성했다. 기존 Ajv 8.20.0을 재사용하며 Python 판정과 실제 Ajv 판정을 정확히 대조한다. 저장된 부모·버전·프로필·전체 사례·규칙 순서와 완료 결과를 Java에서도 결합한다. 새 FILE 스트림은 8 MiB, 기존 세 개를 합한 예약은 56 MiB로 생성기 64 MiB 이내다. 기존 고정·정답·문자열 평가 소스와 지문은 보존한다.

로컬 Core 261, Console 232, 새 Python 11, 새 Node 7 검사가 통과했다. TypeScript·actionlint·공개 프로필 스냅샷·네 스트림 예약 검사도 통과했다. Java 25 로컬 검사는 운영 Java 21 증명이 아니며 Python 검사는 실제 NATS 기동 증명이 아니다. 실제 소스 합성 브라우저 15개 항목에서 오류 0으로 초안 준비 요청 0·명시 등록·scope/role 변경·늦은 응답·잘못된 hash/좌표·409/503·중복 JSON·미지원 스키마·조회자·1440/390 화면을 확인했다. 실제 backend 연결은 없는 합성 fixture 검사다. 후보의 새 편집자·조회자 E2E와 workflow 선택을 작성했지만 아직 실행하지 않았다. 원래 두 사례 다섯 규칙 통과, 금지 도구·잘못된 인자·중복 JSON 실패, 도구 미관측 보류를 실제 후보 NATS/Python/Ajv로 확인한 뒤 수용해야 한다. 최종 소스 커밋·후보 CI·아티팩트 수용이 남아 있다. 저장 화면 구현만으로 이전 완료를 주장하지 않는다.

전체 JSON Schema, 관리자 정책, 동적 공급자, 외부 연결, 범용 데이터셋, 운영 이전은 포함하지 않는다. 원본·압축 사본·R/T·복구 서비스·인증 설정·DB 스키마·실제 배포를 변경하지 않았다.
