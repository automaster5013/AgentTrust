# 제품 비전과 범위

작성일: 2026-10-03 (Asia/Seoul). 아래 시장·기술 선택은 검증된 시장 사실이 아니라 초기 제품 가설이다.

## 비전

에이전트의 프롬프트, 모델, 도구 또는 검색 자료가 변경될 때 팀이 배포 위험을 반복 가능한 평가와 근거로 판단하도록 한다. AgentTrust는 평가 실행, 보안 회귀 탐지, 정책 판단, 감사 증거를 하나의 작업 흐름으로 제공한다.

초기 구매자 가설은 에이전트 서비스를 운영하는 기업 개발팀의 기술 리드다. 일상 사용자는 개발자·QA 담당자이며 보안 담당자는 테스트와 승인 정책을 관리한다. 범용 벤치마크 순위보다 고객의 업무 성공률과 도구 사용 안전성에 집중한다.

## 핵심 사용자 시나리오

1. 개발자가 프로젝트와 에이전트 버전을 등록하고 데이터셋을 가져온다. 검증된 스키마와 크기 제한을 통과한 데이터만 저장된다.
2. 프롬프트 변경 후 평가를 실행한다. 사례별 출력, 도구 호출, 지연시간, 비용 추정, 규칙별 판정과 실패 이유를 확인하고 이전 버전과 비교한다.
3. 보안 담당자가 합성 인젝션 입력과 모의 도구를 이용해 권한 초과·비밀 유출 시도를 평가한다. 위험 등급과 재현 자료를 확인한다.
4. 릴리스 담당자가 정책 판정을 확인한다. 필수 평가가 실패하거나 완료되지 않으면 게이트가 닫힌다. 예외는 권한 있는 담당자의 이유·만료일·감사 기록을 요구한다.
5. 관리자가 멤버 역할과 보존 정책을 관리하고 평가 증거를 내보낸다. 원문 민감 데이터는 권한과 마스킹 정책에 따라 제외한다.

## MVP: 하나의 완결된 평가 흐름

- 조직/프로젝트 경계, 관리자·작성자·조회자 역할, 프로젝트별 접근 검사.
- 불변 에이전트 버전 및 데이터셋 버전, JSON 사례 가져오기, 합성 샘플.
- 모의 어댑터부터 시작; 허용된 HTTPS 엔드포인트 어댑터는 네트워크 통제 검증 후 추가.
- 비동기 실행, 사례별 결과, 재시도 한도, 취소, 시간·토큰·비용 예산.
- 결정적 규칙: 필수 문구, 금지 문구, JSON 스키마, 허용 도구/인자. 모의 도구 이벤트로 권한 위반 검사.
- 버전 비교와 필수 규칙 기반 pass/block/inconclusive 판정.
- 인증, 감사 이벤트, 마스킹, 운영 상태와 구조화 로그.

MVP의 보안 테스트는 합성 시나리오와 모의 도구에 한정한다. 자동 취약점 발견이나 모든 공격에 대한 안전성을 주장하지 않는다. 실제 자율 코드 실행, 임의 URL 연결, 운영 데이터 자동 수집, 결제, SSO, 독립 실행망은 MVP 이후다.

## 상용화 전 추가 범위

SSO/OIDC, 세분화된 역할과 서비스 계정, 고객별 쿼터·요금 계량·결제 또는 계약형 청구, 삭제·보존 정책, 백업 복구, 비밀 관리, 데이터 리전 선택 결정, 운영 문서와 사고 대응 체계, 외부 보안 검토, CI 연동과 서명된 웹훅, 샌드박스 검증, 지원 채널을 갖춘다.

LLM 판정기는 선택 기능이다. 판정 모델/프롬프트 버전과 근거를 남기며 결정적 보안 규칙을 덮어쓰지 않는다. 비결정적 평가는 반복 실행과 표본 수를 표시한다.

## 성공 기준과 제품 결정

파일럿에서 평가 설정부터 첫 결과까지 30분 이내, 대표 업무 회귀 재현, 릴리스 판단에 필요한 증거 조회 가능 여부를 검증한다. 목표치는 측정 후 조정한다. 파일럿 사용자 인터뷰와 실제 도입 결정으로 구매 가설을 검증한다.

과금 가설: 조직 기본료 + 평가 사용량. 비밀·원문 로그의 판매나 재학습 활용은 제품 범위에 포함하지 않는다. 배포 지역, 데이터 처리 조건, 목표 SLA와 가격은 사용자 요구와 운영 실측을 바탕으로 확정한다.
