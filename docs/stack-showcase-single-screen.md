# 한 화면으로 압축한 showcase

2026-11-03 요청에 따라 기존 `/` 및 `/showcase`의 공개 소개를 압축했다. 데스크톱에서 로고·작업공간 진입, 핵심 메시지·판정 예시, 3개 기능·검토 흐름을 한 화면에서 파악하도록 여백과 중복 설명을 줄였다. 합성 예시·현재 게이트와 과거 통과의 차이·소개 화면의 실행 권한 없음은 유지한다. 기존 3개 작업공간 링크와 두 내부 탐색 목적지를 보존한다.

검증 목표는 1366×768, 1440×900 및 1440×1000 CSS 픽셀에서 전체 문서 높이가 viewport 이내인 것이다. 화면 크기·글꼴 확대·브라우저 도구에 따라 공간이 달라질 수 있으므로 `overflow:hidden`으로 내용을 자르거나 작은 글꼴로 무조건 강제하지 않는다. 320/390/768px에서는 자연스러운 흐름과 읽기·키보드 접근을 우선하고 가로 넘침이 없어야 한다. 200% 확대와 아주 짧은 화면에서 세로 스크롤은 허용한다.

`scripts/showcase-ui-review.cjs`가 실제 컴포넌트·CSS로 문서 높이·가로 넘침·skip link·진입 링크를 검사하고 각 화면의 캡처를 남긴다. 테스트 추가 자체는 통과 근거가 아니며 실제 결과를 확인해야 한다. 로컬에서는 타입과 정적 렌더링을 검사했고, 브라우저 검증은 hosted CI에서 실행한다. API 호출·자동 로그인·운영 자료 조회나 쓰기를 추가하지 않았다.

운영의 기존 `43d7801` showcase/sticky Top과 이 후속 소스의 검증·서명 후보·실제 배포는 별도다. 공통 Top 주요 메뉴도 같은 개발 브랜치에서 보강하며, 운영 서비스·기존 자료 보존 및 원래 자원 기준은 유지한다.
