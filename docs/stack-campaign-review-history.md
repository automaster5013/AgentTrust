# 캠페인 검토 이력

선택한 캠페인의 최근 승인·반려 50개를 순서 내림차순으로 조회한다. 검토 사유·검토자 ID·정책 버전과 해시·기록 시각을 표시한다. 과거 승인은 현재 배포 권한이 아니며 현재 게이트를 별도로 확인한다. 이력 조회는 업무 데이터를 생성하거나 변경하지 않는다.

Java API `GET /api/campaigns/{id}/reviews`는 기존 scoped 트랜잭션과 캠페인 admission 검사를 사용한다. 다른 조직이나 존재하지 않는 캠페인은 404다. Gateway와 Console 프록시는 이 GET을 명시적으로 허용하며 POST 검토 저장 보호와 다른 메서드 거부를 유지한다.

화면은 캠페인·조직·프로젝트를 대조하고 중복 ID·잘못된 순서·크기 초과·손상된 정책/시각을 거부한다. 새 조회와 범위 변경은 이전 기록을 지우고, 10초 요청 제한과 취소된 응답의 세대 검사를 적용한다. 실패한 조회는 승인 상태로 표시하지 않으며 수동 재조회로 복구한다.

로컬 검증: Java·Gateway·Console 후보 빌드, Console 101개 검사와 타입 검사, 조회자/관리자 실제 API와 다른 조직/없는 캠페인 404의 네 검사, 실제 브라우저의 정상 조회·다른 범위 응답 거부·503 복구·지연 응답 거부가 통과했다. 적용 전후 업무 테이블 18개를 보존했다. 첫 브라우저 실패는 Gateway GET 경로 누락으로 수정했으며 실패 기록을 보존했다.

`scripts/stack-campaign-review-history-smoke.py`는 기존 캠페인을 읽고 자체 세션을 종료한다. 원래 스택 CI의 소스와 정확한 게시 이미지 경로에 포함된다. 이 문서의 로컬 결과는 해당 변경의 원격 CI·이미지 전달·서명 검증 완료 또는 상용 배포를 증명하지 않는다.

검토 시각은 UTC ISO 형식(`Z` 또는 `+00:00`)과 실제 달력 날짜를 확인한다. 2월 30일·비윤년 2월 29일·24시·시간대가 없는 값은 거부하며 정상 UTC 응답의 소수점 정밀도는 보존한다. 잘못된 시각이 포함된 응답은 이전 검토 행을 남기지 않는다.
