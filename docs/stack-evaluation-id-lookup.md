# 평가 ID로 과거 근거 바로 확인

이전에는 알고 있는 평가도 최근 목록 또는 이력 페이지에서 찾아야 했다. 이제 `이력·감사 → 프로젝트 평가 이력 → 평가 ID로 근거 바로 열기`에서 전체 평가 ID를 입력해 기존 상세 조회와 현재 게이트 조회로 이동한다.

1. 하이픈을 포함한 전체 UUID를 붙여 넣는다. 앞뒤 공백과 영문 대문자는 정규화한다.
2. `평가 ID로 근거 확인`을 누른다. 성공하면 선택한 평가 근거로 초점이 이동한다.
3. 규칙별 근거와 현재 릴리스 게이트를 확인한다. 현재 판정은 실제 배포를 실행하지 않는다.

부분 ID·URL·추가 경로·쿼리는 요청 전에 거부한다. 서버의 기존 조직·프로젝트·역할 검증을 사용하며 다른 조직의 평가는 열지 않는다. 조회가 실패하면 이전에 선택된 근거와 게이트를 제거한다. 존재 여부와 권한 거부를 구분해 노출하지 않는다. 평가 생성·검토 저장·외부 모델 호출은 수행하지 않는다.

이 기능은 정확한 ID 조회이며 전체 이력 부분 검색이 아니다. 타입 검사와 콘솔 계약 검사161개는 통과했다. 정상 조회·실패 후 이전 근거 제거·실제 다른 조직ID 거부의 브라우저 시나리오를 추가했으며, 실제 브라우저 실행은 CI 결과로 별도 수용한다. 현재 d40cdd0 로컬 런타임에는 이 개발 변경을 적용하지 않았다.
