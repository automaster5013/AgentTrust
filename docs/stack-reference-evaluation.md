# 참조 정답 평가

이 경로는 기업 개발팀이 고정한 입력과 기대 정답을 버전으로 등록하고, 실제 로컬 모델의 응답을 두 평가기로 검사하기 위한 것이다. 의미 유사도나 일반적인 AI 품질 점수를 제공하지 않는다. 계약은 `reference-answer-v1`이며 기존 고정 시나리오 계약은 유지한다.

Next.js 화면과 Java API는 데이터셋당 1–2개 사례, 필수 사례 최소 1개, 입력 192 UTF-8 바이트, 정답 128 바이트를 제한한다. Java는 정렬된 계약의 SHA-256과 실행 프로필을 불변 버전에 결합한다. 다른 계약의 에이전트와 데이터셋은 함께 실행할 수 없다. 조직·프로젝트 범위와 역할 검사는 기존 인증 경로를 사용한다.

Python 워커는 별도 JetStream subject `stack.quality-evaluations`를 소비한다. 실행 전에 Java가 저장된 데이터셋의 사례와 입력·정답·해시를 대조하고 기존 단일 사용 공급자 예산을 예약한다. 예약 후 장애가 나면 같은 모델 호출을 반복하지 않는다. 로컬 Ollama와 OpenAI-compatible 경로만 지원하며 두 경로 모두 고정한 같은 로컬 모델을 사용한다.

기대 정답은 모델 프롬프트에 포함하지 않는다. 입력에 고정된 JSON 출력 지시만 추가하며 임의 공급자 URL, 코드, 모델 설정을 받지 않는다. 모델 출력은 최대 2 KiB이며 하나의 문자열 필드 `answer`만 있는 JSON이어야 한다. Python 평가기와 실제 Promptfoo 0.124.1 SDK는 Unicode NFC 정규화와 ECMAScript 공백 제거 후 정확히 비교한다. 둘 다 통과하면 pass, 둘 다 실패하면 block이다. 불일치·검증기 장애·필수 증거 누락은 inconclusive이며 릴리스를 허용하지 않는다.

Promptfoo 검증기는 포트를 호스트에 공개하지 않는 내부 서비스다. 비루트, 읽기 전용 root, 제한된 CPU·메모리·tmp, 내부 네트워크를 사용한다. 인증된 8 KiB 이하 요청과 실행 프로필만 받으며 동시에 하나를 평가한다. 원본 모델 출력은 이 내부 요청의 메모리에서만 처리하고 DB·MinIO·로그·Promptfoo 캐시에 저장하지 않는다. 등록한 입력과 기대 정답은 재현 가능한 데이터셋이므로 불변 버전과 캠페인 기록에 보존한다.

통과한 캠페인도 별도 사람 승인이 필요하다. 현재 승인에는 기존 한 시간 유효기간과 동일 정책 조건을 적용한다. 동결된 부모·자식 증거와 Ed25519 서명 영수증은 과거 관측을 증명하며 현재 배포 권한으로 사용하지 않는다.

검증 명령:

```powershell
python scripts/stack-quality-profiles.py --check
python scripts/stack-quality-verifier-smoke.py
python scripts/stack-quality-campaign-smoke.py
```

Java 55개·Python 77개·TypeScript 계약 25개·실제 Promptfoo SDK 8개 테스트가 통과했다. 내부 검증기 실행 4개 검사와 해당 이미지의 924개 SBOM 구성 요소·HIGH/CRITICAL 0건을 확인했다. 실제 캠페인 검사 9개에서는 두 로컬 API의 총 7개 추론 사례, 불변 버전·범위·정답 불일치·서명된 과거 증거·검증기 장애 및 복구를 확인했다. 새 admission 8개에는 각각 하나의 256/128 토큰 예약만 기록됐으며, 이미 예약한 호출은 워커 복구 후 재실행되지 않았다.

첫 표본의 모호한 출력 지시에서는 실제 모델이 한 정답 사례를 실패해 게이트가 차단됐다. 정상 경로의 새 표본은 명확한 JSON 출력 지시를 사용했고 이전 실패 결과는 그대로 보존했다. 이 검사는 모델의 보편적 정확도를 증명하지 않는다. 브라우저 9개 검사에서는 새 참조 버전 등록·실제 모델 평가·승인·증거 확인·최신 반려와 기존 기능 흐름이 통과했다. 새 15개 이미지 전달 CI 결과는 별도로 기록한다.
